# Starter docs

A new project starts with exactly these three docs. Adapt every placeholder to the project.

| File | Purpose | Owner | Default word limit |
|---|---|---|---|
| `README.md` | What the project is, how to run it, and one headline result and its limit | The owner | 300 |
| `AGENTS.md` | The instructions agents read first (from `templates/AGENTS.md.template`) | The owner approves every change | The template's size |
| `_docs/index.md` | The one place that defines each kind of doc, its folder and what does not belong there (from `templates/docs-index.md`) | The owner | 200 plus one row per entry type |

The word limits are defaults, not measured values. A project may change them; record the change in the index.

Anything else is created at its first entry, in the folder the index names. This set never lists folders: the index's entry-types table is the only place that defines them, so a folder is renamed by editing one row there.

The product spec is human-owned and is not part of this set.

"Owner" is the person who decides what the project's docs hold. By default that is the human.
