# Roadmap <n>: <phase or milestone name>

One file per phase or milestone, named `roadmap-<n>-<slug>.md`, in the folder the index names for planning. The list below is the agreed order (`process.md`, Backlog): every filed issue is added the session it is filed. Order and status only: decisions go in decision records, acceptance criteria stay in the issues, and open or closed is read from the tracker, never written here.

- **Status:** now, next, later or done (one phase is "now")
- **Goal:** <one sentence>
- **Issues or tasks, in order:**
  1. #<number> <a few words>, trigger: <the issue it must land before, or the event that brings it up>
- **Not in this phase:** <links>
- **Archive when:** <condition, for example every issue or task is closed>

Defaults a project may change: at most 300 words per file; when it is done, the owner moves it to the archive.
